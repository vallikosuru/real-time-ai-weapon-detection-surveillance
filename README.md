# Real-Time AI-Based Weapon Detection and Surveillance System

A Python-based real-time surveillance application that uses deep learning models to detect potential weapons from images or video and generate alerts.

## Features

- Real-time weapon detection
- AI-based image analysis
- Computer vision using OpenCV
- Streamlit-based interface
- ONNX Runtime model inference
- Detection confidence scoring
- Alert generation

## Technologies

**Python | Streamlit | OpenCV | ONNX Runtime | NumPy | Pillow**

```text
Image / Video Input
        ↓
Preprocessing
        ↓

        ↓
Alert Generation
